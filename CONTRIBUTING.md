# Contributing

## Setup

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm typecheck
pnpm test
pnpm build
```

## End-to-end tests

```bash
# Install Playwright browsers once
npx playwright install --with-deps chromium

# Run e2e against the dev server (starts automatically)
pnpm test:e2e
```

The Playwright config starts the dev server automatically. `reuseExistingServer` is enabled locally so a running `pnpm dev` is reused.

## Snapshots

Core layout tests use inline snapshots. If you change layout geometry or rendering output, update them:

```bash
pnpm --filter @mordonezdev/logokit-core test -- --update-snapshots
```

## Rules

- Keep the product brand-agnostic.
- Route shared rendering behavior through `packages/core`.
- Add or update snapshots when layout output changes.
- Validate visual changes with Playwright before merging.
- Only `@mordonezdev/logokit` (the CLI) is published to npm. Do not make `packages/core` public.

## Release

Releases are managed by release-please via the `release.yml` workflow. Merge the release PR generated by the bot, then the workflow publishes to npm automatically.
